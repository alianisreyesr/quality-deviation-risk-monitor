# Security Policy

## Supported Versions

This repository is a portfolio prototype. Security fixes are applied to the default branch (`main`) when practical.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the repository owner through the contact details on the GitHub profile with:

- A clear description of the issue
- Steps to reproduce it
- Potential impact
- Any suggested remediation, if available

Do not include credentials, personal data, proprietary information, regulated records, or production system details in a report.

## Data and Portfolio Safety

This project is designed for demonstration purposes only. Use synthetic, non-production data only. It is not a validated GxP system and must not be used as a substitute for approved procedures, validation deliverables, production controls, or regulated decision-making.
