# Portfolio Safety and Intended Use

## Intended use

This repository is a portfolio-safe prototype that demonstrates software engineering, data-quality, and quality-systems design practices.

## Data boundary

All examples, seed data, screenshots, and test fixtures must be synthetic, fictional, or otherwise safe for public sharing. Do not commit:

- Personal or patient information
- Credentials, API keys, tokens, or connection strings
- Proprietary company data or internal documentation
- Production quality records, deviation records, CAPAs, or validation evidence
- Information that could identify a regulated site, product, supplier, or system

## Regulatory boundary

The project may illustrate concepts related to CSV, GAMP 5, ALCOA+, audit trails, and 21 CFR Part 11. It is not a validated GxP system, does not establish compliance, and must not be used for production regulated decision-making.

## Review expectations

Any change that affects scoring, data rules, traceability, or displayed evidence should be reviewed for clarity, reproducibility, and appropriate human oversight.
